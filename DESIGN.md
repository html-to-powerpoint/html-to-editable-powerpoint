# Design

This is a migration and refinement of the existing public example/reference
surface, not a new visual identity. The original HTML sample and example page
are the incumbent visual evidence.

Preserve its light #f5f7fb reading surface, navy #17263d text, blue #245bd1 links,
system sans-serif typography, white document area, dark code blocks and genuine
rendered report image. Use a single reading column, a wrapping navigation row,
clear download links and readable request/response tables. Avoid a pricing funnel
or fabricated marketing illustrations. The sample image is the main visual proof.

All paths must be relative so the site works at a GitHub Pages project subpath.
At narrow widths, stack download controls, keep the image fluid, and constrain
code/table scrolling to their own containers. Provide visible focus, descriptive
download names, and meaningful alt text. Optional copy controls announce results.
