# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Static HTML, CSS and a small optional JavaScript enhancement. GitHub Pages.

## Users
Developers evaluating HTML-to-presentation export for reports and slide tools.

## Product Purpose
Show a real rendered example, make source and output files downloadable, and
explain how to call the existing HTML to Editable PowerPoint API on RapidAPI.

## Capabilities and Constraints
HTML input; binary PPTX, PDF, PNG or JPEG output. Supported text, tables and shapes
can remain editable. Complex effects may rasterize. The documented input contract
is up to 20 slides for PPTX/PDF and one for images. This website performs no API
calls and holds no credentials. Subscription and usage occur on RapidAPI.

## Brand Commitments
Use HTML to Editable PowerPoint as the product name. Keep copy factual and direct.
No engine attribution, invented customers, testimonials or performance promises.

## Evidence on Hand
The existing report example uses explicitly illustrative data. Regenerate output
files through the active API and check slide/text/table objects before publication.

## Product Principles
- Let the actual export demonstrate editability.
- Keep the complete source available with the output.
- Make documentation work without JavaScript.
- Keep secret and operational configuration out of this public repository.
