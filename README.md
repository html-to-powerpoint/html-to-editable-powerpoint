# HTML to Editable PowerPoint — examples and documentation

Static HTML showcase for the [API on RapidAPI](https://rapidapi.com/zhouxinyu1001/api/html-to-editable-powerpoint).

- `index.html`: a real report example and downloadable exports.
- `api-reference.html`: request parameters and a cURL example.
- `usage.html`: layout guidance and output limitations.
- `examples/`: self-contained HTML, request JSON and generated output files.
- `openapi.json`: consumer-facing API definition using the RapidAPI gateway.

The report contains illustrative data. This repository contains no renderer
backend, API credentials, user decks, payment processing or API execution proxy.
It is a documentation/example site; calls and subscriptions are handled by RapidAPI.

GitHub Pages publishes `main` from the repository root. No build is required.
Preview locally with `python -m http.server 8000` and open `http://localhost:8000`.
Keep all internal links relative to support project-site URLs.
