HTML to Editable PowerPoint API reference

Convert supplied HTML slides to PPTX, PDF, PNG or JPEG with one JSON request.

Endpoint: POST https://html-to-editable-powerpoint.p.rapidapi.com/api/render

Authenticate with your X-RapidAPI-Key and X-RapidAPI-Host: html-to-editable-powerpoint.p.rapidapi.com. Use Content-Type: application/json.

Request parameters

Parameter Type Description
slides array of strings, required One complete HTML document per slide. 1–20 for PPTX/PDF; exactly one for PNG/JPEG.
type string pptx, pdf, png or jpeg; defaults to pptx.
title string Output filename title.
aspectRatio string 16:9 or 4:3; defaults to 16:9.

Design on a 960 × 540 CSS-pixel canvas for 16:9 or 960 × 720 for 4:3. Keep all content within the canvas and total JSON below the 10 MB gateway limit. Prefer self-contained HTML, inline styles and image data URLs. Check external fonts and images with a representative request before integrating.

cURL example

Subscribe to a plan on the API listing. Download the report request, or create request.json with this minimal payload and set RAPIDAPI_KEY to your own key:

{"slides":["<html><body><h1>Hello, PowerPoint</h1></body></html>"],"type":"pptx","title":"Example","aspectRatio":"16:9"}

Run this in a shell that supports $RAPIDAPI_KEY environment variable expansion:

curl --fail-with-body --request POST \
  --url 'https://html-to-editable-powerpoint.p.rapidapi.com/api/render' \
  --header 'Content-Type: application/json' \
  --header 'X-RapidAPI-Host: html-to-editable-powerpoint.p.rapidapi.com' \
  --header "X-RapidAPI-Key: $RAPIDAPI_KEY" \
  --data-binary @request.json \
  --output example.pptx

The response is a binary file, not JSON or a download URL. Check the HTTP status before opening the saved file; --fail-with-body may save an error body. In PowerShell use curl.exe and $env:RAPIDAPI_KEY instead.

For PDF, change type in the request to pdf and the output filename to example.pdf. For PNG or JPEG use a single slide.

Responses

Status Meaning
200 Binary PPTX, PDF, PNG or JPEG. Read Content-Type and Content-Disposition.
400 Invalid input, slide count, format or aspect ratio.
401 / 403 Authentication or plan access denied by the service or gateway.
413 Input size exceeds a limit.
429 Rate, quota or concurrency limit. Honor Retry-After when supplied.
500 / 504 Conversion failed or timed out. Simplify or split the input.

The gateway waits up to 180 seconds for the origin. Split large or complex requests into smaller batches. Each successful output slide uses one Slides unit; failed conversions use zero Slides units, but requests have a separate quota. A response whose headers have been sent may already be billed even if the download is interrupted. Retries are new conversions.

X-PPTXRenderer-Slide-Count reports successful output pages. Check X-RateLimit-Slides-Remaining for your subscription's remaining page allowance when supplied by RapidAPI; the output page count alone is not a quota balance.

Supported elements remain editable where possible; complex effects may be rasterized. Test representative HTML before integrating.
