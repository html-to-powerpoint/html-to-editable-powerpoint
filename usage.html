HTML to Editable PowerPoint

Convert HTML slides into editable PowerPoint presentations. Use the same API to export PDF documents and PNG or JPEG images.

Key features

  • Editable PPTX: supported text, shapes, tables and charts become PowerPoint objects.
  • Four output formats: PPTX, PDF, PNG and JPEG from one endpoint.
  • Batch export: up to 20 slides per PPTX or PDF request.
  • Slide layouts: 16:9 widescreen and 4:3 standard.

Use it for business reports, proposals and HTML layouts from AI presentation tools. Supply your HTML and CSS, then save the response as a file.

One endpoint, four output formats

Output Use it for Slides per request
PPTX Presentations with supported editable objects 1–20
PDF A presentation ready to read or share 1–20
PNG / JPEG Slide images for previews and thumbnails 1

Use 16:9 or 4:3 layouts. Submit JSON to POST /api/render and save the binary response as a file. Authentication and plan access are managed through RapidAPI.

What stays editable?

Supported text, shapes, tables and charts can become native PowerPoint objects. Complex visual effects may be rasterized, and support depends on the HTML/CSS used. Test a representative slide for typography, layout and editability before rolling out a large integration. This endpoint renders supplied HTML; it does not generate content or import existing PowerPoint files.

Quick start

Subscribe to a plan, then POST JSON to /api/render using the RapidAPI host and key shown in the Endpoints tab. Save the response as a binary file.

{

  "title": "Example",
  "type": "pptx",
  "aspectRatio": "16:9"
}

Use type: "pdf", "png" or "jpeg" for other exports. PNG and JPEG require exactly one slide. Supported aspect ratios are 16:9 and 4:3.

Layout and assets

  • Use a 960 × 540 CSS-pixel canvas for 16:9, or 960 × 720 for 4:3. Position all content inside these bounds; oversized HTML is not auto-fit.
  • Prefer self-contained HTML, inline CSS and data URLs for images.
  • Check external fonts and images with a representative request before integrating.
  • Use fonts available to the renderer or supported web fonts. Supply a sample deck to check typography and complex layouts before a large integration.
  • The API exports HTML slides; it does not import or parse uploaded PPTX files.

ECharts and tables

Supported ECharts charts export as native PowerPoint charts with editable data, including bar, line and pie charts. PowerPoint controls the final layout. Unsupported chart types or effects may become images.

HTML tables export as native PowerPoint tables with editable cells.

Limits and billing

  • Submit at most 20 slides per request and keep total JSON below 10 MB.
  • The gateway waits up to 180 seconds for the origin. Large or complex jobs may need smaller batches. The slide-count limit is not a completion-time guarantee.
  • Each successfully rendered output slide consumes one Slides unit. Monthly plans also have a Requests hard cap; pay-per-use charges separately for Requests. See Pricing for limits, unit prices and rate limits.
  • Failed conversions consume zero Slides units. Validation errors may still count toward the Requests quota.
  • Billing starts when output headers are sent. A broken download may already be billed. Retries are new conversions; idempotency and range resume are not supported. Do not retry a successful conversion automatically.
  • BASIC, PRO and ULTRA use hard limits with no slide overage billing.
  • MEGA has no monthly subscription. It charges $0.06 per successful output slide, plus $0.00003 per request. Failed conversions use zero Slides but may still incur request and bandwidth fees.
  • The public Pricing page displays a 10,240 MB monthly platform bandwidth allowance for all plans; additional bandwidth is $0.001/MB. Check the current RapidAPI Pricing tab before subscribing.

Errors and support

400 indicates invalid input; 413 indicates excessive input size. For 429, respect Retry-After when present and retry with backoff. For 500 or 504, simplify or split the input before retrying. Gateway errors may use RapidAPI's own format.

For support, use the provider contact/discussion controls on this RapidAPI listing. Include the request time, any request ID, output type, slide count and a minimal non-sensitive reproduction. Never post API keys or confidential decks.
